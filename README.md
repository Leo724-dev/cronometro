# ⏱️ Cronômetro Web - Timer Digital Interativo

Este projeto é uma aplicação web minimalista e interativa desenvolvida para funcionar como um cronômetro digital preciso, contando com funções de controle temporal e uma interface moderna e altamente estilizada.

## 📝 Sobre o Projeto

O foco principal é oferecer um utilitário de medição de tempo limpo, funcional e com excelente feedback visual:
- **Controle de Fluxo Computado:** A aplicação gerencia estados de contagem em tempo real através de funções assíncronas e intervalos no JavaScript.
- **Painel de Três Comandos:** Possui botões intuitivos organizados na parte inferior para reiniciar (reset), iniciar/pausar (play/pause) e marcar voltas ou paradas parciais (lap/flag).
- **Estética Minimalista Dark:** O componente centralizado conta com uma borda circular iluminada e display em alta definição, contrastando com um plano de fundo gradiente moderno em tons de roxo.

## 📸 Demonstração

Você pode visualizar o projeto online através do link: 👉 https://leo724-dev.github.io/cronometro/

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do display numérico e dos botões de controle através de ícones funcionais.
- **CSS3:** Customização avançada com fundos gradientes (`linear-gradient`), layout centralizado absoluto, cantos arredondados, bordas estilizadas e design totalmente limpo.
- **JavaScript (ES6+):** Lógica matemática para incremento preciso de milissegundos, segundos, horas e minutos, manipulação dinâmica de eventos de clique e atualização síncrona do DOM.

## ✨ Funcionalidades

- [x] **Contagem de Alta Precisão:** Formatação digital contínua exibindo horas, minutos, segundos e frações de tempo.
- [x] **Controles Intuitivos:** Suporte completo para pausar, retomar e zerar o temporizador instantaneamente.
- [x] **Design Moderno e Imersivo:** Layout no formato Dark Mode com forte apelo visual e paleta de cores harmoniosa.
- [x] **Responsividade:** Interface compacta e centralizada, otimizada para o uso confortável em telas mobiles ou desktops.
